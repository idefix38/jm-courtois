## Palette de couleurs

| Token Tailwind | Hex       | Rôle                                           |
| -------------- | --------- | ---------------------------------------------- |
| `vert-profond` | `#24333A` | Titres forts, boutons principaux, footer, logo |
| `vert-sauge`   | `#45645B` | Éléments secondaires, liens, icônes            |
| `vert-gris`    | `#7A8D7D` | Fonds secondaires, illustrations               |
| `beige`        | `#C8B99A` | Accents, soulignements actifs, détails         |
| `beige-clair`  | `#E9E5DB` | Fonds de sections, cartes, séparateurs         |
| `blanc-casse`  | `#F6F6F2` | Fond principal                                 |
| `anthracite`   | `#1E1E1E` | Texte courant                                  |
| `gris-doux`    | `#6F6F6F` | Descriptions, légendes, nav inactive           |

Le couple principal de l'identité : **`#24333A` + `#F6F6F2`**.

## Typographies

### Titres — Playfair Display

- Variable CSS : `--font-playfair`
- Classe Tailwind : `font-serif`
- Usage : titres principaux (`h1`–`h6`), citations, mises en avant
- Caractère : littéraire, sensible, intemporel

### Sous-titres / Navigation — Montserrat SemiBold

- Variable CSS : `--font-montserrat`
- Classe Tailwind : `font-display`
- Usage : menu (uppercase + tracking-widest), boutons, labels, catégories
- Poids recommandé : 600

### Texte courant — Source Sans 3 (ex Source Sans Pro)

- Variable CSS : `--font-source-sans`
- Classe Tailwind : `font-sans`
- Usage : paragraphes, résumés, biographies, formulaires
- Poids : 400 / 600

### Signature — Corinthia

- Variable CSS : `--font-corinthia`
- Classe Tailwind : `font-script`
- Usage : logo `jm`, signature manuscrite uniquement — **ne pas utiliser pour les paragraphes ou les titres**
- Poids : 400 (regular)

---

## Hiérarchie typographique

```
Playfair Display  →  émotion / littérature / titres
Montserrat        →  structure / navigation / boutons
Source Sans 3     →  lecture / information / corps de texte
Corinthia         →  émotion / signature / détail
```

## Règles d'usage des couleurs

- **Fond principal** : `blanc-casse` (`#F6F6F2`)
- **Fond sections alternées** : `beige-clair` (`#E9E5DB`)
- **Titres** : `vert-profond` (`#24333A`)
- **Corps de texte** : `anthracite` (`#1E1E1E`)
- **Liens / icônes** : `vert-sauge` (`#45645B`)
- **Accents / soulignements actifs** : `beige` (`#C8B99A`)
- **Texte secondaire** : `gris-doux` (`#6F6F6F`)
- **Footer / fond sombre** : `vert-profond` (`#24333A`)

Les textures (papier, eau, aquarelle, ombres végétales) s'utilisent à **5–15 % d'opacité**.
